USE YOUR OWN PHOTOS IN THE GALLERY
1. Put photos in this folder (jpg/webp, ~1600px wide is plenty).
2. Create gallery/manifest.json mapping the place name to the file:
   {
     "Mysore Palace": "mysore-palace.jpg",
     "Jog Falls": "jog-falls.jpg"
   }
Place names must match the names in js/gallery.js. Anything listed here wins over the Wikipedia photo.
